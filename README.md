# Uzbek Text Simplifier (юридический домен)

готовый приложение в app

Упрощение сложных узбекских юридических текстов (lex.uz) для обычного
читателя.

> **Изменение скоупа (по фидбеку научного руководителя):** мультидоменный
> корпус и опциональный перевод — исследовательски рискованны без
> объективной метрики упрощения для узбекского. Core сужен до одного
> домена — **law**. Вся старая информация (мультидоменный корпус,
> sports.uz, перевод NLLB-200 и т.д.) неактуальна, перенесена в `v1/`.

## Архитектура

1. Parallel-корпус: сложный ↔ простой текст, только домен `law`
2. Fine-tuning mT5-small
3. Демо: Gradio, деплой на HuggingFace Spaces

*(Перевод на ru/en убран из core, перенесён в optional/backlog)*

## Структура репозитория

- `uz_yur_parser.py` — сбор юридического корпуса (lex.uz)
- `prompts/` — инструкция для teacher-модели (v2, рабочая)
- `simplify_state.py` — resume-логика генерации parallel-пар
- `train/finetune_mt5_small.ipynb` — обучение mT5-small
- `app/` — Gradio-демо
- `v1/` — устаревшая версия: мультидоменный корпус (3320 чанков,
  включая wikipedia/news/sports), старые отчёты `docs/`

## Датасет

`domain_legal.csv` — **1104 пары** (сложный текст lex.uz → упрощённый,
сгенерировано teacher-моделью по инструкции v2).

## Открытые вопросы (до полноценного обучения)

По фидбеку научного руководителя, требуют решения до финального прогона:

- **Text-level dedup** — текущий дедуп по `url+chunk_id` не ловит
  повторы текста с разным chunk_id; нужен дедуп по нормализованному тексту
- **Лицензирование источников** — уточнить права на использование
  текста lex.uz для обучения/публикации модели
- **Human-evaluation протокол** — teacher-generated таргет не
  верифицирован объективной метрикой; нужна ручная оценка по трём
  осям: простота, сохранение смысла, фактические ошибки

## Обучение

- База: `google/mt5-small`, task-prefix `"simplify: "`
- Данные: `domain_legal.csv` (1104 пары, только домен `law`)
- Оптимизатор Adafactor, LR 1e-3, 8 эпох, `fp16` выключен (mT5 даёт
  NaN loss в half precision)
- Метрики на валидации (эпоха 6/8): ROUGE-L ≈ 0.28, chrF ≈ 44.7,
  монотонный рост без плато

## Статус

Скоуп сужен до `law`, модель уже обучена на legal-only данных
(`domain_legal.csv`). До публикации/защиты нужно закрыть три пункта
выше (dedup, лицензии, human-eval протокол) — метрики есть, но без
human-eval их доказательная сила ограничена.
